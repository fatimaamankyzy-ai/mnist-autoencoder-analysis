# Autoencoders on MNIST: Feature Extraction & Latent Space Analysis

Deep learning project exploring unsupervised feature learning using Fully-Connected, Convolutional, and Variational Autoencoders on the MNIST handwritten digit dataset.

The project compares different autoencoder architectures in terms of reconstruction quality, learned latent representations, dimensionality reduction, generative capability, and denoising performance.

## Project Overview

Autoencoders learn compressed representations of high-dimensional data by reconstructing their inputs through an encoder-decoder architecture.

In this project, three architectures are implemented and compared:

- **Fully-Connected Autoencoder (FC-AE)** — baseline dense neural network
- **Convolutional Autoencoder (Conv-AE)** — preserves spatial image structure using convolutional layers
- **Variational Autoencoder (VAE)** — learns a probabilistic latent representation and enables generation of new samples

All models are trained and evaluated on the **MNIST dataset**, containing 60,000 training and 10,000 test images of handwritten digits.

## Objectives

The analysis focuses on:

- Comparing reconstruction performance across autoencoder architectures
- Visualizing learned latent representations using **t-SNE and PCA**
- Investigating the effect of latent dimensionality
- Evaluating latent-space interpolation
- Exploring the generative capabilities of Variational Autoencoders
- Testing implicit image denoising
- Understanding how different architectures learn representations without class labels

## Model Architectures

### Fully-Connected Autoencoder

A baseline autoencoder that flattens each 28×28 image into a 784-dimensional vector.

```text
784 → 256 → 64 → latent space → 64 → 256 → 784
```

### Convolutional Autoencoder

Uses convolutional layers to preserve spatial relationships between pixels and learn local features such as edges and strokes.

```text
Input
  ↓
Convolutional Encoder
  ↓
Latent Representation
  ↓
Transposed Convolutional Decoder
  ↓
Reconstructed Image
```

### Variational Autoencoder

Learns a probabilistic latent space rather than deterministic embeddings.

The encoder learns the parameters of a Gaussian distribution and uses the reparameterization trick for sampling.

This enables:

- Smooth latent-space interpolation
- Generation of new digit images
- More structured latent representations

## Training

The models were implemented using **PyTorch** and trained for 20 epochs using a GPU.

Main configuration:

| Parameter | Value |
|---|---|
| Optimizer | Adam |
| Learning Rate | 0.001 |
| Batch Size | 128 |
| Epochs | 20 |
| Baseline Latent Dimension | 16 |
| FC-AE / Conv-AE Loss | Mean Squared Error |
| VAE Loss | BCE + KL Divergence |

## Results

### Reconstruction Performance

| Model | Parameters | Test MSE |
|---|---:|---:|
| Fully-Connected AE | ~215K | 0.0113 |
| **Convolutional AE** | ~470K | **0.0082** |
| Variational AE | ~475K | 0.0128 |

The **Convolutional Autoencoder achieved the lowest reconstruction error**, demonstrating the advantage of preserving spatial information when working with image data.

The VAE sacrifices some reconstruction accuracy in exchange for a smoother and more structured latent space.

## Latent Space Analysis

Latent representations were analyzed using both **t-SNE** and **PCA**.

Despite being trained without class labels, the models learned representations in which handwritten digits form distinct regions in latent space.

The Convolutional Autoencoder produced tighter class groupings, while the VAE generated a more uniformly structured latent space due to KL regularization.

## Effect of Latent Dimensionality

The Convolutional Autoencoder was evaluated using latent dimensions:

```text
2 → 4 → 8 → 16 → 32 → 64
```

Reconstruction error decreased substantially as the latent dimension increased up to approximately **16 dimensions**, after which improvements became relatively small.

A 16-dimensional representation compresses the original 784-dimensional image by approximately:

**49:1**

while maintaining strong reconstruction quality.

## Generative Modelling

The Variational Autoencoder allows new handwritten digits to be generated by sampling from the learned latent distribution.

The structured latent space also enables smooth interpolation between digits, with intermediate latent vectors decoding into plausible digit-like images.

## Denoising

The models were also evaluated on images corrupted with Gaussian noise.

Although none of the architectures were explicitly trained as denoising autoencoders, all three demonstrated implicit denoising ability.

The **Convolutional Autoencoder produced the cleanest reconstructed images**, showing that the compressed representation can act as a natural noise filter.

## Key Findings

- Convolutional architectures outperform fully-connected autoencoders for image reconstruction.
- Conv-AE achieved the best reconstruction performance with **MSE = 0.0082**.
- Autoencoders learn meaningful digit representations without using class labels during training.
- A latent dimension of approximately **16** provides a strong compression-quality trade-off.
- VAE produces a smoother and more structured latent space suitable for generation and interpolation.
- Autoencoder bottlenecks provide implicit denoising capability.
